错误返回记录

建议核对清单

  • 先确认是测试环境还是正式环境，不要混用域名和 Token。
  • 把 Postman 示例和前端实际请求逐项比对，重点看 Header。
  • 发现 4xx 或 5xx 时，先记录原始请求与返回，再继续改动。

常见问题

为什么同一个接口在前端和 Postman 结果不一样？

常见原因是 Header、Cookie、跨域处理或请求体格式不同。

联调记录应该怎么留？

建议至少保留请求示例、返回结果、时间和环境说明。

输入与结果

适合先用示例验证格式，再换成自己的内容继续处理。

JSON 输入

{ "code": 0, "data": { "name": "demo" } }

结果示例

{
  "code": 0,
  "data": {
    "name": "demo"
  }
}
01

先校验格式

确认引号、逗号和括号层级是否正确，避免结构错误影响联调。

02

再看字段差异

重点看是否少字段、字段名不同或嵌套层级改变。

03

最后保存示例

把成功和失败示例都留存，方便后续定位问题。

  • JSON 工具页适合配合接口文档一起使用，让开发和测试看到同一套结构。
  • 如果返回值经常变化，建议同步更新示例，而不是只在聊天里口头说明。

常见问题

为什么格式正确仍然联调失败？

可能是字段语义、类型或层级不匹配，而不只是语法问题。

适合给非技术同事看吗？

适合，只要配清楚字段说明和成功示例。

01

先查解析是否生效

重点看 A 记录、CNAME 或 CDN 返回是否符合预期。

02

再看状态码与跳转

确认首页、登录页和表单页没有意外的 301、302 或 5xx。

03

最后核对地区差异

如果有 CDN 或海外节点，建议再补一轮不同地区访问检查。

  • 解析正常不代表页面一定正常，仍要结合状态码和页面内容一起看。
  • 站点刚切换域名或证书时，缓存和地区传播差异很常见。

常见问题

为什么 DNS 已经生效但页面还是旧的？

通常和本地缓存、CDN 缓存或浏览器缓存有关。

HTTP 200 就一定没问题吗？

不一定，还要确认页面内容、跳转链路和关键接口是否正常。

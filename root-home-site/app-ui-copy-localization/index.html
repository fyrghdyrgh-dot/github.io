应用界面文案本地化要先看什么

适合按钮、弹窗、设置页和引导页本地化，重点是长度、语气和上下文一致性。

01

先看上下文

同一个词在按钮、标题和设置项里的翻译方式可能完全不同。

02

再看长度约束

UI 文案比普通正文更容易因为字数和排版出问题。

03

最后统一语气

确认系统语气、按钮风格和错误提示是否一致。

建议核对清单

  • 界面文案不要脱离页面上下文单独翻译。
  • 重点按钮建议在真机或设计稿里再看一遍长度。
  • 错误提示和确认弹窗要统一语气。
